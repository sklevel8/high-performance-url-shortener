How a redirect happens

The hot path is deliberately boring: one cache read, one 302, one async write.

Node.js · PostgreSQL 18 · Redis
01

Redis first

The short code is looked up in Redis. A warm hit returns in well under 10 ms without touching Postgres.

GET url:6LAze
02

Postgres fallback

On a miss the row is read from Postgres and written back to Redis with a 24-hour TTL. Redirects never wait on analytics.

SELECT id, original_url
FROM urls WHERE short_code = $1
03

Fire and forget

The 302 is sent immediately. The click event is written asynchronously with a salted SHA-256 IP hash.

302 → original_url
↳ INSERT INTO clicks …
